# wikivazr: запуск

1. Данные (Google Диск): script.google.com → Новый проект → вставь `apps-script/Code.gs`,
   замени ключ, Deploy → New deployment → Web app (Execute as: Me, Access: Anyone), скопируй URL.
2. Хостинг: перетащи папку `wiki-app` (без папки apps-script) на https://app.netlify.com/drop
3. На телефоне открой адрес в Chrome → меню → «Установить приложение».
4. В приложении: Ещё → вставь URL и ключ → «Сохранить и синхронизировать». Потом Ещё → «Выбрать CSV» для импорта из Notion.
